## Link policy

There are no authored Markdown text links or HTML hyperlinks in presentation
files. Source attribution is plain text. Video playback, case inspection,
filtering, answer reveal, and all three date selections work in place. Local
asset loading is permitted; original news URLs remain in JSON for provenance.

Git hosting platforms control their own account navigation, file browser,
image viewers, and Markdown heading anchors. A repository cannot disable those
platform features. For anonymous review, distribute the anonymous mirror or
the history-free archive, not the identifiable source-host URL.

The source repository and anonymous mirror are independent deployments. A source
push does not demonstrate mirror synchronization. Refresh the mirror in its
owner dashboard and confirm the `Navigation audit: 2026-09-25` marker.
