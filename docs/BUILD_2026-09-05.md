## What is verified

- 121/121 items are from English sources; 90/121 (74.4%) have numeric or temporal
  answers. They cover 24 sources and five categories. Science/technology is
  overrepresented (77/121); this is not a claim of balanced topic coverage.
- The final packaging audit checks publication age within 48 hours, exact
  evidence offsets and source hashes, image/question deduplication, P0 records,
  and all 24 recorded P1/P2 verdicts per item.
- All 2,904 public certification trials match their private API responses,
  recorded prompts/decoding settings, and grading records. This verifies log
  linkage; it is not an independent reassessment of model judgments.
- P1/P2 remain relative to the actual construction panel. Generator and panel
  share a Doubao member. Human review is pending; held-out transfer was not run.
- Construction and scoring code changed during debugging. Run manifests retain
  executed-code hashes and each item retains its actual grader version. Newer
  code is not retroactively attributed to earlier calls.
